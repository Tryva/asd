# Security policy

ASD is a detector, not an autonomous safety guarantee. Review its evidence and
apply host policy deliberately.

## Reporting a vulnerability

Use GitHub Security Advisories for this repository to report a vulnerability
privately when that feature is available. Do not disclose secrets, credentials,
or exploitable details in a public issue. If private reporting is unavailable,
contact the maintainers before publishing sensitive details.

`UNKNOWN` must not be converted to an automatic `DENY` by ASD. Hosts remain
responsible for their own security and enforcement decisions.
